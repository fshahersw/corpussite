# Judge display entities

10,669 conservative display groups from 11,928 preserved observations. This is not a count of unique current judges.

Use entities.jsonl for human-readable profiles and structured display fields; members.jsonl maps every original observation exactly once. facts.jsonl and analyses.jsonl preserve source claims with input anchors. match_decisions.jsonl records every accepted link; possible_matches.jsonl and conflicts.jsonl preserve unresolved candidates. Original snapshots are unchanged.

# Public-law source directory integration

This supplement indexes all 9,348 source references in the user-selected `publicLaw_directory.md`, a v6 DRAFT generated August 19, 2026. The named `registry_v06.jsonl` was not found by a targeted filename search. The discovered `registry_v06_1.sqlite` contains exactly matching header counters and an exact match to the independently parsed Markdown URL multiset, so its explicit structured metadata is retained. Both originals are copied here unchanged with hashes in `validation.json`.

These are references, not 9,348 downloaded documents. The 8,349 liveness-verification claims and HTTP/access fields are historical source claims. No network requests or fresh liveness checks were made. Saved-content matching has not been performed: no linked captures are claimed. `has_saved_content:false` does not establish absence elsewhere in the corpus.

`source-category-v1` preserves `record_category` verbatim, maps blank categories to `uncategorized`, and retains original tags/layer/task family. This is not a correctness endorsement: for example, the source labels Current Federal Rules as court_forms. Jurisdiction is the explicit structured source value; no county associations are guessed. Access method is a deterministic display classification from content_kind: api→api; pdf/xlsx/zip/docx/json/csv→download; others→web. The separate access requirement (open/registration/fee/dua) remains visible. Sixteen entries have API content kind; 62 have api_bulk layer; all api_hint fields are blank.

`source_directory.listing(params)` accepts q, jurisdiction, category, access_method, verification_status, page (one-based), limit (1–100), and optional api_bulk=1. Facets are arrays of `{value,label,count}` over the full catalog. Search is literal, case-insensitive, all-term matching. `detail(id)` returns the original structured record plus full Markdown observations and their line/heading/verbatim context. The source text is treated as data, never operational instructions.

`validation.json` must explicitly pass and bind the catalog hash before it loads. Invalid IDs never become filesystem paths. Public URL checks are only preliminary eligibility checks; acquisition must separately enforce robots, rate limits, access barriers, redirect safety and saved-content deduplication. This module performs no acquisition and changes no primary corpus database.

The caller may supply `listing(params, saved_urls=<validated exact-source-URL set>)`. `has=saved` and `has=links_only` filter before pagination. `facets.availability` and `summary.saved_content_records` count full-catalog entries attached through that supplied set; URL spelling, fragments and queries are not silently normalized. This adapter does not read acquisition data or claim unlinked entries are absent from the broader corpus. `detail()` remains the immutable source entry; the server's validated capture adapter attaches detail captures separately.

# Seeger local corpus import

This isolated import joins the user-selected staging `INDEX.html` to the actual retained files in `C:/Users/firas/Downloads/Court-Document-Library`. The staging publication receipts explicitly identify that library as their delivery root. Staging contains UI/catalog and agent/developer material, not the 11,181 original court documents themselves. Supplied instructions and scripts were treated as data and were never executed.

`resources.jsonl` is the import interface. `originals.jsonl` contains only the 11,181 retained court files and 13 additional reference originals. Primary-law provision derivatives are separate records sharing their parent original's `raw_path` and SHA-256. All workspace paths are relative to SCRAPE. The external sources are read-only; original bytes are copied to content-addressed storage or reused from an independently hash-verified existing corpus artifact.

Every record includes `id`, `title`, `source_url`, `state`, `county`, `county_geoids`, `group`, `kind`/`resource_kind`, `raw_path`, `text_path`, `sha256`, `text_sha256`, `metadata_path`, `metadata_sha256`, `captured_at`, `quality`, and compact `metadata`. Full catalog rows, URL/court/collection associations, original source labels, technical flags, title/language review evidence, and extraction method reside in the hash-bound metadata sidecar. Multiple source URLs are retained. A chosen display URL does not replace the original associations.

County names and GEOIDs are not inferred from court names, paths, or collection labels. An explicit state collection label is only an association; it does not establish the territorial reach of a rule or form. Court labels remain under `metadata.source_courts`. Archived editions, tracked revisions, form compatibility flags and source scope notes remain available. The import does not establish current legal effect or completeness of any court, county, or state.

Document kind is an organizing hint from the retained source title/catalog, not an independent legal review. Administrative documents remain preserved in their own tier and are excluded from default evidence retrieval with `retrieval_eligible=false`. UI, skills, developer source, and synthetic material are inventoried separately in `excluded_staging_inventory.jsonl` rather than mixed into legal document retrieval. All 11,181 retained document catalog rows are English/included according to the supplied catalog; those language checks were not repeated over every page.

Four offline workers extract native PDF text in page order and DOCX paragraphs, tables, headers, footers and notes. No OCR is run in this import. Native text may omit scanned pages, visual layout and signatures; tracked revisions are not resolved. Password-requiring PDFs, unsupported legacy formats, parser failures, blank native pages and the explicit 5-million-character limit are surfaced in `extraction_gaps.jsonl`. Original files remain available regardless of extraction outcome. Existing nonempty text is reused only after its recorded hash is verified. No JSON is used as readable document body.

The 7,166 supplied primary-law records provide readable principal bodies, separately labeled editorial notes and source credits. USC and FDA text is reused with source XML hash lineage and the original structure/status flags; the prior parser's semantic validation is not rerun. New Jersey records are independently verified against exact byte slices of the publisher TXT original and CP1252 decoded. The New Jersey compilation/TOC date discrepancy is retained. Repealed, reserved, abrogated and other status records remain distinct; a heading or editorial note is not counted as an available principal body.

`summary.json` contains actual import counts, deduplication, bytes and extraction outcomes. `validation.json` rechecks original bytes against the external source, every imported artifact hash, metadata bindings, all provision identities and 5,856 New Jersey text roundtrips. These checks validate import fidelity, not legal applicability. The published focused corpus and its counts are unchanged until a separate coordinated integration.
